# AInxiety

面向开发者的 AI 新闻采集与编辑工作流：持续监听多个来源，将报道聚合为事件，输出摘要和原始链接，发布少量重大快讯以及定时日报、周报。

当前阶段：方案设计。尚未实现采集、模型调用或对外发布。

## 仓库结构

本项目采用单仓库、多服务结构；Sleep Blog 保持独立仓库。服务边界与部署边界不依赖仓库拆分。

```text
AInxiety/
├── apps/
│   ├── core/           # 采集、事件记忆、编辑、订阅与投递
│   └── qq-bot/         # 独立 QQ 服务：发送、回执、反馈
├── adapters/
│   ├── email/          # 邮件发送模块
│   └── sleep-blog/     # AInxiety 一侧的博客对接
├── contracts/          # 公开协议与消息 Schema
├── deploy/             # 服务构建与部署配置
└── docs/               # 设计、来源及验收计划
```

当前目录以职责说明建立骨架，没有可运行应用。Core 与 QQ Bot 通过公开接口通信，不跨服务访问数据库。

## 已确认的产品方向

- 重大事件及时推送，日常消息进入日报、周报。
- 每天推送频率保持个位数；内容采用摘要＋链接。
- 关注开发者技术进展及 AI 热点，通过用户反馈调整偏好。
- Agent 与 QQ Bot 独立设计，支持多个来源和多个发布渠道。
- 下游包含博客、QQ Bot 和邮箱；优先实现按订阅主动推送，再实现离线恢复拉取，两者共用投递记录。
- 个人博客是 `/srv/workspaces/sleep-blog/repo` 中的 Spring Boot＋Vue 项目。
- 使用事件记忆与语义判断处理跨来源重复报道，并识别实质性进展。
